# Visual Art Direction

&gt; This document defines the visual design direction of the Curling Performance Platform.

&gt;

&gt; Unlike the Design System, it does not define components, spacing tokens or implementation details.

&gt;

&gt; Unlike the Visual Product Identity, it does not define the product's personality.

&gt;

&gt; Instead, it describes the visual language that should make the product instantly recognisable and emotionally consistent across every screen.

&gt;

&gt; Every future design decision should reinforce this visual identity before introducing additional visual complexity.

---

# Purpose

A user should be able to recognise the product without seeing its logo.

The platform should have a distinctive visual character that communicates professionalism through restraint rather than decoration.

The goal is not originality for its own sake.

The goal is consistency.

---

# Design DNA

The product should feel like a modern performance instrument.

It combines the clarity of scientific software with the warmth of a carefully crafted consumer product.

It should communicate:

- precision

- confidence

- calm

- focus

- craftsmanship

- premium quality

It should never feel generic.

---

# Spatial Philosophy

Space is one of the primary design tools.

The interface should breathe.

Layouts should never feel compressed simply to display more information.

Likewise, they should never feel artificially empty.

Whitespace should create rhythm, separation and confidence.

Not decoration.

---

# Surface Philosophy

Surfaces should be used intentionally.

Not everything deserves its own container.

Whenever possible:

- allow the page background to create openness

- group related content naturally

- reduce unnecessary visual boundaries

- let hierarchy emerge through spacing before elevation

Containers should communicate importance—not merely separation.

---

# Material Language

The product should feel tangible without mimicking physical materials.

Avoid heavy skeuomorphism.

Avoid exaggerated glass effects.

Avoid visual trends that may quickly feel dated.

Instead, favour subtle depth, carefully controlled elevation and restrained use of shadows.

Surfaces should appear refined rather than decorative.

---

# Shape Language

The interface should feel engineered.

Shapes should communicate stability and precision.

Rounded corners should soften the interface without making it playful.

Avoid sharp contrasts between different corner radii.

Consistency is more important than individuality.

---

# Density Philosophy

Information density should adapt to the user's intent.

Execution screens should prioritise clarity over quantity.

Analysis screens may become denser while maintaining strong hierarchy.

The product should never attempt to impress through the amount of visible information.

Instead, it should communicate confidence through thoughtful organisation.

---

# Contrast Philosophy

Contrast directs attention.

Not every element should compete equally.

Use contrast deliberately to create a clear visual path through every screen.

Important information should naturally attract attention.

Supporting information should quietly remain available.

Avoid relying on colour alone to create hierarchy.

Typography, spacing and scale should lead first.

---

# Rhythm

Every screen should feel composed rather than assembled.

Visual rhythm emerges through variation.

Alternate between:

- open space

- contained information

- strong focal points

- lightweight supporting content

Avoid long sequences of visually identical sections.

Rhythm should make scrolling feel effortless.

---

# Visual Balance

The interface should always feel balanced.

Large visual elements should be offset by quieter areas.

Dense sections should be followed by breathing room.

No individual section should visually dominate unless it represents the primary task of the screen.

Balance creates trust.

---

# Premium Characteristics

Premium software rarely appears complicated.

It appears intentional.

Characteristics of a premium interface include:

- disciplined alignment

- restrained colour usage

- generous but purposeful spacing

- high-quality typography

- minimal visual noise

- consistent proportions

- subtle motion

- clear hierarchy

Premium should emerge through refinement—not luxury effects.

---

# Colour Character

Colour should support meaning.

Never decoration.

Most of the interface should remain visually neutral.

Accent colours should communicate:

- current actions

- important metrics

- meaningful state changes

Large areas of saturated colour should be used sparingly.

The athlete's data—not the interface—should become the visual focus.

---

# Motion Character

Motion should communicate continuity.

Transitions should reinforce the user's mental model.

Animations should feel:

- smooth

- responsive

- subtle

- predictable

Avoid motion that exists solely for entertainment.

The best animation is often the one that goes unnoticed.

---

# Visual Restraint

Every additional visual element increases cognitive load.

Before adding:

- another colour

- another border

- another icon

- another card

- another shadow

- another animation

ask whether hierarchy or spacing could solve the same problem more elegantly.

The simplest successful solution is usually the strongest.

---

# Premium Through Reduction

Design quality often comes from what is removed.

Reduce:

- unnecessary borders

- redundant labels

- decorative icons

- duplicated actions

- excessive shadows

- competing visual accents

Every removed distraction increases the visibility of what truly matters.

---

# Emotional Consistency

The interface should evoke the same emotional response on every screen.

Users should consistently feel:

- focused

- calm

- confident

- in control

Individual features may differ.

The overall emotional tone should remain stable.

---

# Visual Timelessness

The product should remain visually relevant for many years.

Avoid following short-lived design trends.

Choose solutions that prioritise clarity over novelty.

A timeless interface evolves gradually rather than reinventing itself with every redesign.

---

# Design References

The product should draw inspiration from software that communicates quality through restraint.

Useful references include:

- Linear

- Arc Browser

- Oura

- WHOOP

- Flighty

- Apple Fitness

- Polar Flow

These products should inspire principles rather than visual imitation.

---

# Anti-Patterns

Avoid interfaces that resemble:

- enterprise dashboards

- spreadsheet applications

- banking software

- generic SaaS templates

- overly gamified fitness apps

- social media products

- component libraries assembled without hierarchy

The interface should always feel intentionally designed—not constructed from interchangeable UI blocks.

---

# Final Principle

Every visual decision should answer one question:

&gt; Does this make the athlete's training experience feel clearer, calmer and more professional?

If not, the design should be simplified before additional elements are introduced.
